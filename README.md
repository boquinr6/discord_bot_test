## In Discord

Resources:

- https://discord.com/developers/applications
- https://discord.com/developers/docs
- https://discordpy.readthedocs.io/en/stable/

Steps on Discord:

- In https://discord.com/developers/applications
- Create an account if you don't have one
- Create a new application
- Go to "Bot". Make sure you set it to be Public
- Click 'Reset Token' and copy the token and put it in the .env file
- Enable Server Members and Message Intents
- Go to "OAuth2" -> "URL Generator"
- Use the URL to invite the bot to your server
